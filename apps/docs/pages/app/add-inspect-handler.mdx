# addInspectHandler

Appends an inspect request handler to the list of handlers managed by the application.

## Usage

Below is a simple example of adding an inspect handler that only logs the request received.

```ts twoslash
import { createApp } from "@deroll/app";

// create application
const app = createApp();

app.addInspectHandler(({ payload }) => { // [!code focus]
    console.log(payload); // [!code focus]
}); // [!code focus]
```

## Returns

`void`

## Parameters

Type: `InspectRequestHandler`

A function that receives the inspect request, which carries only a `payload`. It may be `async`, but it does not have to be.
