# addAdvanceHandler

Appends an advance request handler to the list of handlers managed by the application.

## Usage

Below is a simple example of adding an advance handler that only logs the request received.

```ts twoslash
import { createApp } from "@deroll/app";

// create application
const app = createApp();

app.addAdvanceHandler(async ({ msgSender, payload }) => { // [!code focus]
    console.log(msgSender, payload); // [!code focus]
    return true; // [!code focus]
}); // [!code focus]
```

## Returns

`void`

## Parameters

Type: `AdvanceRequestHandler`

An async function that receives an object with the decoded input fields (`chainId`, `appContract`, `msgSender`, `blockNumber`, `blockTimestamp`, `prevRandao`, `index` and `payload`), and returns a boolean: `true` accepts the input, `false` rejects it.
