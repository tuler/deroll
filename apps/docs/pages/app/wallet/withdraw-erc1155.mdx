# withdrawErc1155

Withdraw ERC-1155 tokens from one user, returning an `Erc1155Transfer` that transfers the tokens to the user on L1.
Emit it with [createErc1155Transfer](/app/create-erc1155-transfer).

## Usage

The following example withdraws the entire balance of token id 1 of the user who is submitting an input to the application.

```ts twoslash
import { createApp } from "@deroll/app";
import { createWallet } from "@deroll/wallet";

// create app
const app = createApp();

// create wallet
const wallet = createWallet();

app.addAdvanceHandler(wallet.handler);

const token = "0x04d724738873CB6a86328D2EbAEb2079D715e61e"; // ERC-1155 address
app.addAdvanceHandler(async ({ msgSender }) => {
    const value = wallet.erc1155BalanceOf(token, msgSender, 1n);
    if (value > 0) {
        app.createErc1155Transfer( // [!code focus]
            wallet.withdrawErc1155(token, msgSender, 1n, value), // [!code focus]
        ); // [!code focus]
    }
    return true;
});
```

## Returns

Type: `Erc1155Transfer`

The transfer fields (`recipient`, `token`, `tokenId`, `value`), ready for [createErc1155Transfer](/app/create-erc1155-transfer).

## Parameters

Type: `Address`

Address of ERC-1155 token.

Type: `Address`

User to withdraw from (and L1 recipient).

Type: `bigint`

Id of the token.

Type: `bigint`

Amount to withdraw.
