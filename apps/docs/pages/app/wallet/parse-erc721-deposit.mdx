# parseEtherDeposit

Parse a ERC-721 deposit request coming from the `ERC721Portal` smart contract.

## Usage

```ts twoslash
import { createApp } from "@deroll/app";
import { isErc721Deposit, parseErc721Deposit } from "@deroll/wallet";

// create app
const app = createApp();

app.addAdvanceHandler(async (data) => {
    if (isErc721Deposit(data)) {
        const deposit = parseErc721Deposit(data.payload); // [!code focus]
// @noErrors
        deposit.
//              ^|
    }
    return true;
});
```

## Returns

Type: `Erc721Deposit`

Structure with deposit data.

## Parameters

Type: `Hex`

Deposit payload.
