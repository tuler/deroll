# encodeCallVoucher

Encodes a **call voucher** — a one-shot on-chain transaction authorized by the application: a destination, an ether value, and calldata. Once the epoch containing it settles, the voucher can be executed through the application contract, exactly once.

`encodeCallVoucher` is a pure-JS helper that returns the EVM-ABI encoded output as 0x-hex (a `CallVoucher(bytes32,address,uint256,bytes)` call, mirroring libcmt's `cmt_call_voucher_encode`). Emit them with [`emitOutput`](/rollup/reference/emit-output) to add the voucher to the outputs merkle tree (provable).

## Usage

Plain value transfer:

```ts twoslash
import { Rollup } from '@deroll/rollup';
import { encodeCallVoucher } from '@deroll/codec';
const rollup = new Rollup();
// ---cut---
const index = rollup.emitOutput(
    encodeCallVoucher({
        destination: '0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266',
        value: 1_000_000_000_000_000_000n, // 1 ETH in wei
        payload: '0x', // no calldata — plain value transfer
    }),
);
```

Contract call (calldata in `payload`):

```ts twoslash
import { Rollup } from '@deroll/rollup';
import { encodeCallVoucher } from '@deroll/codec';
const rollup = new Rollup();
declare const calldata: `0x${string}`; // e.g. ERC-20 transfer(address,uint256)
// ---cut---
rollup.emitOutput(
    encodeCallVoucher({
        destination: '0x6B175474E89094C44Da98b954EedeAC495271d0F',
        value: 0n,
        payload: calldata,
    }),
);
```

The output index comes from [`emitOutput`](/rollup/reference/emit-output)'s return value: the voucher's position among all provable outputs ever emitted by the application. Off-chain components use it to fetch the voucher's proof for execution.

## Returns

`Hex` — the encoded voucher as a 0x-hex string, ready to pass to [`emitOutput`](/rollup/reference/emit-output).

## Parameters

### destination

- Type: `Hex` — 0x-prefixed hex string (20-byte address)

The address the voucher executes against: an EOA for transfers, a contract for calls.

### appContext

- Type: `Hex` — 0x-prefixed hex string (32 bytes)
- Optional; defaults to the zero hash (`0x00…00`)

Free-form application-defined tag carried by the output; recipients can filter outputs by it.

### value

- Type: `bigint`

Amount of wei sent with the execution (`0n` for none). Must fit in an unsigned 256-bit integer.

### payload

- Type: `Hex` — 0x-prefixed hex string

EVM calldata to execute at `destination` (`0x` for a plain transfer).

## Errors

Invalid arguments throw [ox](https://oxlib.sh) errors, e.g. `Address.InvalidAddressError` for a malformed `destination` or `Hex.IntegerOutOfRangeError` for an out-of-range `value`.
