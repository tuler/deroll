# withdrawErc721

Withdraw an ERC-721 token from one user, returning an `Erc721Transfer` that transfers the token to the user on L1.
Emit it with [createErc721Transfer](/app/create-erc721-transfer).

## Usage

The following example withdraws the token 1 of the user who is submitting an input to the application.

```ts twoslash
import { createApp } from "@deroll/app";
import { createWallet } from "@deroll/wallet";

// create app
const app = createApp();

// create wallet
const wallet = createWallet();

app.addAdvanceHandler(wallet.handler);

const token = "0xc6582A9b48F211Fa8c2B5b16CB615eC39bcA653B"; // NFT address
app.addAdvanceHandler(async ({ msgSender }) => {
    const hasOne = wallet.erc721Has(token, msgSender, 1n);
    if (hasOne) {
        app.createErc721Transfer(wallet.withdrawErc721(token, msgSender, 1n)); // [!code focus]
    }
    return true;
});
```

## Returns

Type: `Erc721Transfer`

The transfer fields (`recipient`, `token`, `tokenId`), ready for [createErc721Transfer](/app/create-erc721-transfer).

## Parameters

Type: `Address`

Address of ERC-721 token.

Type: `Address`

User to withdraw from (and L1 recipient).

Type: `bigint`

Id of the token.
