# chain

Composes several advance handlers into the single handler [`Rollup.run`](/app/application) accepts, presenting the input to each in turn until one accepts it.

## Usage

```ts twoslash
/// <reference types="node" />
import { Rollup } from "@cartesi/rollup";
import { createWallet } from "@deroll/wallet";

const rollup = new Rollup();
const wallet = createWallet();
const application = () => true;
// ---cut---
import { chain } from "@deroll/core";

rollup.run({
    advance: chain(wallet.handler, application), // [!code focus]
});
```

The wallet sees every input first and claims the ones that are portal deposits. Anything it declines falls through to `application`.

## Returns

Type: `AdvanceRequestHandler`

A handler that accepts the input if any of the composed handlers accepted it, and declines if none did — so an input no handler recognized is rejected by the loop.

## Parameters

### handlers

Type: `AdvanceRequestHandler[]`

The handlers, in the order they should see the input. Each returns `true` to claim the input or `false` to pass it on; see [Advance Handlers](/app/advance-handlers).

## Short-circuiting

Once a handler accepts, the ones after it are not called:

```ts twoslash
/// <reference types="node" />
import { Rollup } from "@cartesi/rollup";
import { chain } from "@deroll/core";

const rollup = new Rollup();
// ---cut---
rollup.run({
    advance: chain(
        () => false,
        () => true,
        () => {
            // never runs: the previous handler already accepted // [!code hl]
            return true;
        },
    ),
});
```

Use [broadcast](/app/broadcast) when every handler should see the input regardless.

## Exceptions

`chain` does not catch handler exceptions. They propagate to the loop, which rejects the input and emits the error as a report — and the handlers after the one that threw do not run.

That is deliberate: an input that could not be processed should be rejected, and running later handlers would risk writing state on top of a partially applied one. To decline an input without aborting the chain, return `false` instead of throwing.
