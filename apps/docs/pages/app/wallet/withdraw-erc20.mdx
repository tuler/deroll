# withdrawErc20

Withdraw ERC-20 tokens from one user, returning an `Erc20Transfer` that transfers the tokens to the user on L1.
Emit it with [createErc20Transfer](/app/create-erc20-transfer).

## Usage

The following example withdraws the entire CTSI balance of the user who is submitting an input to the application.

```ts twoslash
import { createApp } from "@deroll/app";
import { createWallet } from "@deroll/wallet";

// create app
const app = createApp();

// create wallet
const wallet = createWallet();

app.addAdvanceHandler(wallet.handler);

const token = "0x491604c0FDF08347Dd1fa4Ee062a822A5DD06B5D"; // CTSI address
app.addAdvanceHandler(async ({ msgSender }) => {
    const value = wallet.erc20BalanceOf(token, msgSender);
    if (value > 0) {
        app.createErc20Transfer(wallet.withdrawErc20(token, msgSender, value)); // [!code focus]
    }
    return true;
});
```

## Returns

Type: `Erc20Transfer`

The transfer fields (`recipient`, `token`, `value`), ready for [createErc20Transfer](/app/create-erc20-transfer).

## Parameters

Type: `Address`

Address of ERC-20 token.

Type: `Address`

User to withdraw from (and L1 recipient).

Type: `bigint`

Amount to withdraw.
