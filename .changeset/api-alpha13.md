follow the rollups-node 2.0.0-alpha.13 JSON-RPC API (`@cartesi/client` 2.0.0-alpha.38, `@cartesi/react` 2.0.0-alpha.42, `@cartesi/codec` 1.0.0-alpha.5 with the new contract addresses): the node bar reads `cartesi_getNodeInfo` (chain, version and the node's default block) instead of the deprecated `getChainId`/`getNodeVersion`; applications no longer report data availability and gain the GUEST_EXCEPTION/MACHINE_HALTED/MCYCLE_OVERFLOW/UNEXPECTED_YIELD/INVALID_OUTPUTS_ROOT statuses; epochs replace the outputs merkle root/proof with the TX-buffer, iflags.Y and HTIF tohost data blocks and their proofs; inputs replace `outputsHash` with `txBufferDataBlock`, show the guest's exception data, and drop the resource-limit statuses for OVERFLOW/UNEXPECTED_YIELD/INVALID_OUTPUTS_ROOT. Tournaments show their kind, initial hash, base cycle, clock allowance, creation tx and a current-state snapshot (standing, candidate/winner, inner result, bond recovery) plus their bond refund/recovery events; commitments show claimer and clock; matches show phase, timeout outcome, bisection/sealed state, deadlines and leaf seal, with advances keyed by tx hash and log index. The overview adds executed and pending executable output counts, and the outputs list gains an Executed filter. The mock server serves the new shapes and methods
