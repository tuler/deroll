## [App](/app/quick-start)

Develop Cartesi applications in TypeScript. A small set of composable libraries —
`@deroll/app`, `@deroll/wallet`, `@deroll/router` — for writing the backend that runs
inside the Cartesi Machine: handle inputs, manage assets, and emit notices, reports and
vouchers.

## [Bindings](/cmio/getting-started)

Low-level communication with Cartesi. Native Node.js bindings for the guest rollup
library ([`@deroll/cmio`](/cmio/getting-started)) and the Cartesi Machine itself
([`@deroll/cm`](/cm)) — the foundation the higher-level libraries build on.

## [Explorer](/explorer)

Observability for Cartesi. A web UI for navigating a rollups node — applications, epochs,
inputs, outputs, reports and tournaments — plus [`@deroll/decoder`](/explorer/decoders)
for turning raw payloads into readable summaries.
