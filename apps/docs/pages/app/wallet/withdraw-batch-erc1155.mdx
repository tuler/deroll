# withdrawBatchErc1155

Withdraw multiple ERC-1155 tokens from one user, returning an `Erc1155BatchTransfer` that transfers the tokens to the user on L1 in a single batch.
Emit it with [createErc1155BatchTransfer](/app/create-erc1155-batch-transfer).

## Usage

The following example withdraws the entire balance of token id 1 and 2 of the user who is submitting an input to the application.

```ts twoslash
import { createApp } from "@deroll/app";
import { createWallet } from "@deroll/wallet";

// create app
const app = createApp();

// create wallet
const wallet = createWallet();

app.addAdvanceHandler(wallet.handler);

const token = "0x04d724738873CB6a86328D2EbAEb2079D715e61e"; // ERC-1155 address
app.addAdvanceHandler(async ({ msgSender }) => {
    const value1 = wallet.erc1155BalanceOf(token, msgSender, 1n);
    const value2 = wallet.erc1155BalanceOf(token, msgSender, 2n);
    if (value1 > 0 && value2 > 0) {
        app.createErc1155BatchTransfer( // [!code focus]
            wallet.withdrawBatchErc1155( // [!code focus]
                token, // [!code focus]
                msgSender, // [!code focus]
                [1n, 2n], // [!code focus]
                [value1, value2], // [!code focus]
            ), // [!code focus]
        ); // [!code focus]
    }
    return true;
});
```

## Returns

Type: `Erc1155BatchTransfer`

The transfer fields (`recipient`, `token`, `items`), ready for [createErc1155BatchTransfer](/app/create-erc1155-batch-transfer).

## Parameters

Type: `Address`

Address of ERC-1155 token.

Type: `Address`

User to withdraw from (and L1 recipient).

Type: `bigint[]`

Ids of the token.

Type: `bigint[]`

Amounts to withdraw.
