# withdrawEther

Withdraw L2 ETH (or base layer native token) from one user, returning a `CallVoucher` that transfers the value to the user on L1.
Emit it with [createCallVoucher](/app/create-call-voucher).

## Usage

The following example withdraws the entire balance of the user who is submitting an input to the application.

```ts twoslash
import { createApp } from "@deroll/app";
import { createWallet } from "@deroll/wallet";

// create app
const app = createApp();

// create wallet
const wallet = createWallet();

app.addAdvanceHandler(wallet.handler);

app.addAdvanceHandler(async ({ msgSender }) => {
    const value = wallet.etherBalanceOf(msgSender);
    if (value > 0) {
        app.createCallVoucher(wallet.withdrawEther(msgSender, value)); // [!code focus]
    }
    return true;
});
```

## Returns

Type: `CallVoucher`

The voucher fields (`destination`, `value`, `payload`), ready for [createCallVoucher](/app/create-call-voucher).

## Parameters

Type: `Address`

User to withdraw from (and L1 recipient).

Type: `bigint`

Amount to withdraw.
